# Лабораторна робота №4 — варіант 15

Перевантаження операцій в C++

Варіант 15 із лабораторної №2. Створити клас Fraction із закритими полями: ціла частина — long зі знаком, дробова — unsigned short. Реалізувати додавання, віднімання, множення та порівняння; зберегти Init(), Read(), Display(), toString(). На основі проєкту лабораторної №3 з трьома конструкторами й деструктором обрати 3–4 операції та реалізувати їх перевантаження. Обрано рівно чотири оператори: +, -, *, ==. Сформувати звіт.

## Збирання і запуск у Windows

Потрібен GCC MinGW-w64 з підтримкою C++14. Додайте каталог `bin` компілятора до `PATH` або передайте його скрипту через параметр `-CompilerDirectory`.

```powershell
.\build.ps1
Get-Content .\input.txt | .\lab04.exe
```

Команди збирання

```text
g++ -std=c++14 -O2 -Wall -Wextra -pedantic -static-libgcc -static-libstdc++ fraction.cpp main.cpp -o lab04.exe
```

У `input.txt` збережені тестові вхідні дані, а в `expected_output.txt` — вивід перевіреного запуску.
